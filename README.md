# Sử ký YBA Gia Định (2009 – 2026)

Trang sử ký Chi hội Gia Định – Hội Doanh nhân Trẻ TP. Hồ Chí Minh: biên niên các nhiệm kỳ VII → XII → Ban Điều hành nhiệm kỳ I, những người gánh vác, mạch truyền thống, dòng thời gian và album ảnh tư liệu, kèm bài hát *Giữ Ấm Đường Xa*.

Trang tĩnh, không cần build: mở `index.html` hoặc bật GitHub Pages (Settings → Pages → Deploy from branch `main`, thư mục `/`).

- `data.js` — nội dung và danh mục ảnh (sinh tự động từ bộ công cụ biên soạn).
- `assets/anh/` — ảnh tập thể (`*_t.webp` thu nhỏ, `*.webp` xem lớn); `assets/cn/` — chân dung Chủ nhiệm các thời kỳ.
- `fonts/` — Cormorant Garamond, Be Vietnam Pro (SIL Open Font License).

Ảnh thuộc về Chi hội Gia Định và các tác giả. Chốt tư liệu 18/11/2026.
